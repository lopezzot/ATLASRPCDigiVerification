# ATLASRPCDigiVerification
A set of tools for developing and validating the phase-II digitization of the ATLAS RPCs

- [transmissionlines/](./transmissionlines) — C++ emulator of a signal induced by a spike on an RPC strip
- [validation/](./validation) - Code to create plots using the ATLAS RPC digitization output files
